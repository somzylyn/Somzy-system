SOMZY SYSTEM — PROJECT AWAKENING

PHONE-ONLY DEPLOYMENT (FREE)

1. Extract this ZIP on your Android phone.
2. Open https://github.com in Chrome and sign in or create a free account.
3. Create a new public repository named somzy-system (GitHub Pages is available for public repositories on the free plan).
4. In the repository, choose Add file > Upload files.
5. Upload index.html, manifest.json, sw.js, icon.svg, icon-192.png and icon-512.png from the extracted folder. Commit the files.
6. Open repository Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
8. Wait for the Pages URL to appear. Open it in Chrome on Android.
9. Chrome menu (three dots) > Add to Home screen or Install app, if offered.

IMPORTANT:
- This is a static personal-use web app (PWA), not a native APK.
- The app saves data locally in the browser on this device. Export a JSON backup regularly.
- GitHub Pages public repositories make the app source publicly viewable. Do not put private journal entries, passwords, or sensitive information in the source code. The app's saved local data is not uploaded to GitHub.
- Use the app URL only for your own use; do not share it if you want the interface private.
- A free GitHub account and public repository are required for this no-cost hosting route.
- Browser support for installing PWAs varies. If install is unavailable, bookmark the URL or use Add to Home screen.
